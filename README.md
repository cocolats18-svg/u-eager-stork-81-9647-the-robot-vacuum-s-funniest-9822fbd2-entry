One line in which a robot vacuum explains why it missed a spot:

> "I didn't miss that spot — the dust bunny unionised, and my suction respects a picket line."

## How it works

`main.ts` writes the single excuse line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`). A length gate throws unless the line is 1–120
characters. The program is fully deterministic: no network, no randomness.
